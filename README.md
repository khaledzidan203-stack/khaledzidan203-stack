## How I Build Analytics

**Business Problem → Analytical Questions → Grain & Keys → Data Quality → KPI Contracts → Data Model → Validation → Visualization → Insight → Action**

My projects consistently emphasize:

- validating **grain, keys and relationships before aggregation**
- separating **zero, missing, suppressed and not-applicable values**
- using governed and reusable KPI definitions
- reconciling important metrics independently
- preserving source anomalies instead of hiding them
- separating descriptive evidence from unsupported causal claims
- designing dashboards around **business decisions, not decoration**
- keeping analytics reproducible and reviewable through source control and validation
